# PhotoshopDKV

A Laravel-based photography marketplace for managing and selling digital photos.

## Overview

PhotoshopDKV is a web application designed for photographers and customers to manage and purchase digital photography products. The project focuses on photo management, product information, inventory, pricing, and user-based marketplace workflows.

## Features

- User authentication and authorization
- Photo and product management
- Photo categories and descriptions
- Pricing, stock, and size management
- Photo upload and file management
- Product status management
- Customer and seller workflows
- Responsive web interface

## Tech Stack

- PHP
- Laravel
- MySQL
- Blade
- HTML
- CSS
- JavaScript

## Architecture

The application follows Laravel's MVC architecture:

- **Models** — Database entities and relationships
- **Controllers** — Application logic and request handling
- **Views** — User interface built with Blade
- **Routes** — Web application endpoints
- **Migrations** — Database schema management
- **Middleware** — Authentication and access control

## Purpose

This project was built as a practical implementation of full-stack web development concepts, including CRUD operations, authentication, database integration, file uploads, and marketplace workflows.
